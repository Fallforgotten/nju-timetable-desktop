# 南大课表导出助手

Windows 桌面课表导出工具。无需安装浏览器插件，在程序内登录南京大学教务平台，确认学期和筛选范围，即可逐页汇总课程并保存为本地 JSON。

**v0.1.2 · Windows x64 · 非南京大学官方应用**

## 下载

在本仓库的 **Releases** 中下载 `nju-timetable-assistant-v0.1.2-win-x64.zip`，完整解压后运行 `NJU-Timetable-Assistant.exe`。

- 无需 Node.js、Python 或浏览器扩展。请保留全部文件，不要只复制 EXE，也不要在压缩包内直接运行。
- **Code → Download ZIP** 下载的是源码，不是可运行程序。
- 程序未签名，Windows 可能提示未知发布者。请核对来源并遵循设备安全策略，无需关闭安全软件。

## 使用步骤

1. 点击 **打开南大教务平台**，校外可尝试 **校外访问入口**，自行登录。
2. 选择 **学生组（不是本科组）→ 全部课程**。
3. 选择学期和筛选条件，点击搜索，回到第一页。
4. 点击 **检查当前课表**，核对学期及教学班总数。
5. 点击 **确认范围并导出全部**，确认后等待完成；不要修改筛选或手动翻页。
6. 选择本机 JSON 保存位置。需要使用时，可点击 **打开蹭课网**，手动导入文件。

导出范围是当前筛选结果。也可识别“我的课表”中的个人课程列表。

### 分页栏有两个，或不能识别下一页？

点击左侧 **指定下一页按钮**，再点击学校页面实际分页栏的 **下一页**（常见为从左数第三个方形按钮）。本次点击只绑定、不翻页。看到已指定后，点击 **检查当前课表**，核对信息后导出。

可点击 **取消指定** 退出；60 秒未选择会自动取消。页面刷新分页控件后，需重新指定。

### 其他问题

| 情况 | 操作 |
| --- | --- |
| 学期缺失或截断 | 填写与页面一致的完整学期，例如 `2026-2027学年 第1学期`，再检查。 |
| 未找到课表 | 确认学生组、全部课程，点击搜索并等待加载。 |
| 想中途停止 | 点击停止，可保存已读取的部分结果；文件会标明未全部完成。 |
| 取消了保存 | 点击“保存导出结果 JSON”重试；退出程序会丢失未保存结果。 |
| 登录不兼容 | 可回退[浏览器插件](https://github.com/Fallforgotten/nju-timetable-exporter)。 |

## 功能与适用范围

- 内置学校入口，自动翻页、进度显示、停止与本地保存。
- 检查页码连续性、学期、总数和重复记录；每次翻页前至少等待 1.5 秒。
- 单次最多 20,000 条；不将中断结果报告为完整。
- 仅适配南京大学支持的页面。学校系统变更可能需要更新适配。
- 不自动选择身份组、不更改选课、不提供额外访问权限。

## 隐私

登录由学校网页完成。程序不提取或导出密码、Cookie、学生名单，使用独立的非持久会话，不继承其他浏览器登录，退出后不保留该会话。

课程只在内存汇总，由使用者选择路径保存。程序不自动上传课表、不遥测、不云同步、不自动更新。学校页面本身仍需联网完成认证和查询；打开蹭课网不会自动传递文件。

输出沿用 `cengke-nju-visible-v1` 格式，包含课程号、教学班名称、教师、时间地点等课程字段，以及学期、范围和完成状态。仓库测试课表均为虚构数据，不包含真实课表、账号或登录票据。

## 开发与构建

在 Windows 上使用符合依赖要求的 Node.js（本版本在 Node.js 24 环境验证）：

```sh
npm ci
node node_modules/electron/install.js
npm test
npm run test:smoke
npm start
npm run build
```

首次安装需要联网下载依赖与运行时。显式安装 Electron 可兼容不自动执行依赖安装脚本的 npm 配置。

- `npm test`：策略单测。
- `npm run test:smoke`：隐藏窗口和虚构课表自检，无需学校账号；输出在 `.test-output/`。
- `npm run build`：生成 `release/0.1.2/NJU-Timetable-Assistant-win32-x64/`，将完整目录压缩为 Release 附件。相同输出已存在时请先归档旧产物。
- 可选 `NJU_ELECTRON_ZIP_DIR` 环境变量指向已缓存的官方 Electron ZIP 所在目录。

主要文件：`main.cjs` 为主进程；`pager-binding.js` 处理手动分页绑定；`policy.cjs` 校验域名及结果；`preload.cjs` 提供工具栏接口；`vendor/` 保存配套插件 v0.21.0 的提取与分页代码；`tests/` 提供虚构页面与测试；`build.cjs` 按固定源码白名单打包。

学校页面处于沙箱，无 Node.js 和工具栏 IPC 权限。执行提取前检查域名与路径。
